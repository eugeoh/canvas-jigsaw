# Security Policy

## Supported Versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a Vulnerability

Do not open a public issue for a vulnerability that could put users at risk.
Instead, use GitHub's private vulnerability reporting for this repository:

<https://github.com/eugeoh/canvas-jigsaw/security/advisories/new>

Include reproduction steps, affected versions, impact, and any known mitigation.
You should receive an acknowledgement within seven days.
